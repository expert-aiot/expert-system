# White Shrimp UI GitHub Pages Package

This folder contains only the static files needed for the white shrimp platform UI.

- `mobile/`：手機 UI 入口
- `desktop/`：電腦 UI 入口
- `data/`：共用 UI runtime、設定與樣式
- `assets/`：共用圖片與靜態資源

Upload this folder to GitHub Pages. The root `index.html` redirects to `mobile/`.
